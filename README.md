# Rachael Yeboah — Software & Data Engineering Portfolio

Live Website: [rachael804.github.io](https://rachael804.github.io)

This repository contains the source code for my personal developer portfolio. The site is designed to highlight my work across machine learning pipelines, backend services, network simulation, and data systems.

## Tech Stack

- **Markup & Structure:** HTML5
- **Styling:** Tailwind CSS (Dark theme with slate and teal accents)
- **Deployment:** GitHub Pages (Custom user domain)
- **Version Control:** Git & GitHub

---

## Featured Projects Highlighted

1. **AI News Aggregator & Fake News Detector**
   - Automated ingestion pipeline scraping multi-topic news into PostgreSQL using BeautifulSoup.
   - Text classification model for detecting low-credibility and misleading sources.
   - [Repository & Source Code](https://github.com/Rachael804/ear-news)

2. **Enterprise Network Infrastructure Simulation**
   - Corporate network architecture modeled in Cisco Packet Tracer.
   - Implementation of Inter-VLAN routing, 802.1Q trunking, DHCP relays, and serial WAN links.
   - [Repository & Source Code](https://github.com/Rachael804/enterprise-network-simulation)

3. **Customer Churn Prediction Engine**
   - Supervised machine learning system using XGBoost and Scikit-Learn to detect customer attrition risk.
   - Preprocessing pipelines handling high class imbalance and feature importance extraction.
   - [Repository & Source Code](https://github.com/Rachael804/customer-churn-prediction)

4. **Sales Demand Forecasting Engine**
   - Time-series modeling using SARIMAX and Prophet to project retail inventory demand swings.
   - Stationarity testing (ADF), seasonal trend decomposition, and evaluation metrics (MAE, RMSE).
   - [Repository & Source Code](https://github.com/Rachael804/sales-demand-forecasting)
